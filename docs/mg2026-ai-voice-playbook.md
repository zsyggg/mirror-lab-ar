# MG2026 AI / Voice / Gameplay Playbook

## 核心卖点

《镜面实验室》不是把大模型当成开放聊天窗口，而是把它放进推理机制里：

1. 每局开局随机抽取隐藏真相：MORAN、LILA、ZERO 或 Yuki 自我终止。
2. 搜查阶段给出和本局真相匹配的证据变体。
3. 圆桌盘问阶段由 AI 扮演嫌疑人：真凶会保护自己，好人也会隐藏自己的违规。
4. 玩家通过自由追问和出示证据提高嫌疑人的紧张度。
5. 当紧张度达到阈值，嫌疑人出现破防供词；玩家再做最终推论。

这套结构适合比赛汇报：AI 不是外挂答案，而是被规则约束的“动态证词生成器”。

## 语音方案

### 推荐比赛版

使用“关键台词预生成 + 动态盘问不实时配音”的混合方案。

- 开场漫画、任务简报、AI 助手总结、结局台词：预生成高质量音频，放进 `assets/audio/`。
- 嫌疑人自由问答：默认只显示文字，配合短音效和头像动画。
- 重要破防台词：预生成 3 名嫌疑人的多条情绪音频，命中阈值时播放。

原因：上传给官方后，浏览器 SpeechSynthesis 很机械；实时 TTS/API 又依赖网络、密钥和延迟。预生成音频最稳，也最像完整作品。

### 可选技术路线

- 最快质感：OpenAI TTS、MiniMax Speech、ElevenLabs、Azure Neural Voice 这类云端 TTS，生成后把 MP3/WAV 打包进游戏。
- 本地开源：CosyVoice、GPT-SoVITS、Fish Speech、IndexTTS。它们适合离线生成角色音频，但配置和显卡环境更重，不适合作为网页游戏运行时依赖。
- 不推荐：把 DeepSeek 或语音 API Key 直接写进前端。比赛上传后任何人都能看到密钥。要么预生成，要么走服务端代理。

## DeepSeek / 小模型使用边界

前端静态游戏里可以保留本地 Ollama 作为开发增强；比赛版应提供两档：

- 离线稳定档：规则供词 + 预写破防台词，任何评委打开都能玩。
- AI 增强档：本地运行 `scripts/deepseek_proxy.mjs`，由它读取本机 `DEEPSEEK_API_KEY` 或 OpenClaw DeepSeek 配置，再用 `deepseek-v4-flash` 生成更自然供词。前端只连本地代理，不保存密钥。

报告里可以写清楚：核心玩法不依赖远程模型，远程模型只增强角色口供的自然度。

## 下一步玩法优化

1. 证据卡图片化：每张证据对应专门图像，减少文字墙。
2. 圆桌审判：用圆桌背景、嫌疑人头像、紧张条和证据拖拽感形成仪式感。
3. 情绪条：出示命中证据时上涨；达到阈值触发破防台词。
4. 二轮搜查：第一轮建立动机，第二轮给出本局真相专属反证。
5. 最终推论：不是只选凶手，而是选择“密室如何成立”的解释。

## 汇报 PDF 建议结构

1. 游戏概述：科幻密室、远程机器人搜证、AI 圆桌盘问。
2. 创新点：随机真相、动态证词、证据压力条、AI 不给答案而扮演嫌疑人。
3. 技术实现：Three.js 搜查场景、生成式图像资产、本地/云端 LLM 角色 Prompt、预生成 TTS。
4. 美术风格：统一成人科幻动画风格、黑线条、青绿辐射色、证据卡视觉系统。
5. 可玩性：每局线索和真相变化，玩家需要二次搜查与交叉盘问。
6. 风险与兜底：离线规则供词、无 API Key 暴露、语音预生成、静态部署可运行。
